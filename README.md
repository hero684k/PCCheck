# PCCheck v1.0

Portable system analyzer. Scan processes, autostart, scheduled tasks, USB history, recent files and new executables.

## Features

- 6 scan categories: Processes, Registry, Scheduled Tasks, USB, Recent, New Files
- Digital signature verification for all processes
- VirusTotal integration — one click to check any file
- Risk assessment (High/Medium/Low) with color coding
- Filter by Microsoft entries, signed files, or custom text
- Export results to CSV
- Kill processes directly from the interface
- Portable EXE — no installation required
- Light theme, monospace font, alternating row colors

## Download

[Latest Release](https://github.com/hero684k/PCCheck/releases/latest)

## Usage

1. Run `PCCheck.exe`
2. Click **SCAN** or press `Ctrl+S`
3. Browse results in 6 tabs
4. Right-click any item for actions
